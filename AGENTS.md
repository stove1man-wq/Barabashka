# Правила для ИИ-агентов в этом репозитории

## Git
- Работай в своей ветке (не в `main`): `git checkout -b cline/<тема>` от свежего `main`. Перед началом `git pull`.
- После завершения задачи, изменившей файлы: `.\tools\save.ps1 "<кратко, по-русски>"` (add, commit, push в текущую ветку). Без force push. Если push не прошёл, сообщи об ошибке и остановись.
- В `main` вливает владелец проекта после проверки на телефоне.
- В начале сессии прочитай `docs/STATE.md`.

## Контекст (экономим)
- Обзор: `README.md`; устройство: `docs/ARCHITECTURE.md`; планы: `docs/ROADMAP.md`. Читай их, только если задача этого требует.
- Код: `Assets/Scripts/`. Не открывай `.meta`, `.unity`, `.asset`, `ProjectSettings/`, `Library/`.
- Работай только с файлами, указанными в задаче.

## Сеть (обязательно)
1. Ядро (правила, задачи, заметки, голос, локальные файлы) работает без внешней сети. Новая сетевая возможность необязательна и при отказе сообщает человеку понятное сообщение, без падения и без бесконечного ожидания.
2. Не добавляй жёстких зависимостей на зарубежные сервисы: только как необязательный профиль или источник. Новой возможности с сетью указывай `NetworkNeed` и `NetworkZone` в `CapabilityRegistry`. Сеть проверяй через `IConnectivity`, а не сам. Подробнее: `docs/ARCHITECTURE.md`, «Сеть и доступность».

## Правила правок
- Файлы создавай и правь инструментами записи, не через терминал (PowerShell искажает `$` и `\`).
- Новая возможность агента = инструмент `IAgentTool` в `AgentToolRegistry` + правило разбора фразы + запись в `docs/COMMANDS.md`.
- Действия вне приложения (звонок, SMS) подчиняются настройке «Действия агента» (вручную / с подтверждением / полный цикл).
