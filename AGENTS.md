# Правила для ИИ-агентов в этом репозитории

## Git
После завершения каждой задачи, изменившей файлы проекта: `git add -A`, `git commit -m "<кратко, по-русски>"`, `git push origin main`. Без force push. Если push не прошёл, сообщи об ошибке и остановись.

## Контекст (экономим)
- Обзор: `README.md`; устройство: `docs/ARCHITECTURE.md`; планы: `docs/ROADMAP.md`. Читай их, только если задача этого требует.
- Код: `Assets/Scripts/`. Не открывай `.meta`, `.unity`, `.asset`, `ProjectSettings/`, `Library/`.
- Работай только с файлами, указанными в задаче.

## Правила правок
- Файлы создавай и правь инструментами записи, не через терминал (PowerShell искажает `$` и `\`).
- Новая возможность агента = инструмент `IAgentTool` в `AgentToolRegistry` + правило разбора фразы + запись в `docs/COMMANDS.md`.
- Действия вне приложения (звонок, SMS) подчиняются настройке «Действия агента» (вручную / с подтверждением / полный цикл).
