# Правила для ИИ-агентов (Cline, Continue)

Этот файл попадает в каждый запрос: он короткий намеренно. Не расширяй его.

## Экономия запросов и контекста (главное)
1. Задача полностью описана в тексте от архитектора. Не исследуй проект «для понимания»: не листай папки, не делай поиск по всему репозиторию.
2. Читай только файлы, названные в задаче. Нужен другой файл? Сначала `docs/MAP.md` (карта кода), потом точечное чтение нужного файла. Файл читай один раз; большие файлы (больше 300 строк) читай кусками по нужным строкам.
3. После правки не перечитывай файл для проверки: инструмент записи сам сообщит об ошибке. Не повторяй уже сделанные чтения.
4. Правь за один вызов несколько мест файла, а не по одному. Новые файлы создавай целиком одним вызовом.
5. Не рассуждай вслух и не пересказывай план. Не делай «Plan», сразу выполняй (план уже есть в задаче). Сомнение - один короткий вопрос человеку, а не раздумья на страницу.
6. Не запускай сборку, тесты, Unity и `dotnet` из терминала: проект собирает человек в Unity. Не запускай `git status`/`git log` без нужды.
7. Не читай и не правь: `*.meta`, `*.unity`, `*.asset`, `*.prefab`, `ProjectSettings/`, `Packages/`, `Assets/Samples/`, `Assets/Plugins/`, `Library/`. Список в `.clineignore`.
8. Закончил - ответь тремя строками: что изменено (файлы), что проверить человеку, что осталось. Без пересказа кода.
9. Задача не помещается в контекст или ты зациклился: остановись, напиши, на чём стоишь. Не повторяй те же шаги.

## Git
- Своя ветка `cline/<тема>` от свежего `main`; в `main` не пиши. Без force push.
- Сохранение обычными командами: `git add -A`, `git commit -m "<кратко, по-русски>"`, `git push -u origin <ветка>`. Скрипт `tools/save.ps1` может быть заблокирован Windows.
- В `main` вливает владелец проекта после проверки на телефоне.

## Сеть (обязательно)
1. Ядро (правила, задачи, заметки, голос, локальные файлы) работает без внешней сети. Новая сетевая возможность необязательна и при отказе сообщает человеку понятное сообщение, без падения и бесконечного ожидания.
2. Зарубежные сервисы только как необязательный профиль или источник. Новой сетевой возможности укажи `NetworkNeed` и `NetworkZone` в `CapabilityRegistry`; сеть проверяй через `IConnectivity`.

## Правила правок
- Файлы создавай и правь инструментами записи, не через терминал (PowerShell искажает `$` и `\`).
- Новая возможность агента = инструмент `IAgentTool` в `AgentToolRegistry` + правило разбора фразы + запись в `docs/COMMANDS.md`.
- Новая страница настроек = класс `ISettingsPage` + `SettingsRegistry.Register` (см. `Core/Settings/`), без правки интерфейса.
- Действия вне приложения (звонок, SMS) подчиняются настройке «Действия агента».
- Модули независимы: интерфейс, ядро, плагины, сеть общаются через `Assets/Scripts/Contracts/`.
