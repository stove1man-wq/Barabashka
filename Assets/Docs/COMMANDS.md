# Команды голосового управления

## Настройки голосом

Голосовые команды для управления настройками приложения:

### Открытие настроек
- «открой настройки»
- «покажи настройки»
- «открой настройки <страница>»
- «покажи настройки <страница>»

### Страница "Озвучка"
- «включи озвучку»
- «выключи озвучку»

### Страница "Умные ответы"
- «включи умные ответы»
- «выключи умные ответы»
- «включи модель в телефоне»

### Страница "Общие"
- «покажи город» - показывает текущий город
- «покажи время» - показывает текущее время
- «покажи дату» - показывает текущую дату
