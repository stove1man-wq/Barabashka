Положите сюда два файла сертификатов НУЦ Минцифры (формат PEM) под именами:
  mincifry_root.bytes - корневой сертификат (Russian Trusted Root CA)
  mincifry_sub.bytes  - выпускающий сертификат (Russian Trusted Sub CA)

Скачать: https://www.gosuslugi.ru/crt
Корневой напрямую: https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt

Без них GigaChat не работает; остальные модели не затронуты. Файлы публичные, их можно коммитить.
