# Что умеет агент (примеры фраз)

Фразы можно говорить или писать. Слэш-команды работают только текстом.

| Область | Примеры |
|---|---|
| Задачи | «добавь задачу купить хлеб», «покажи задачи», «удали задачу 2», «переименуй задачу 2 в …» |
| Заметки | «запиши заметку …», «покажи заметки» |
| Напоминания, таймеры | «напомни через 10 минут …», «поставь таймер на 5 минут», «покажи напоминания» |
| Будильник | «разбуди меня в 7 утра», «будильник на 6:30», «покажи будильники» |
| Время, даты, счёт | «который час», «какое сегодня число», «сколько будет 12 умножить на 7» |
| Погода | «узнай погоду», «погода в Казани», «мой город Самара» |
| Телефон | «включи фонарик», «сделай громче», «громкость на 50», «сколько заряда» |
| Интернет, карты | «найди в интернете …», «открой ютуб», «проложи маршрут до …» |
| Приложения | «открой телеграм», «запусти камеру», «открой калькулятор» |
| Звонок | «позвони маме», «позвони Ивану Петрову», «набери номер плюс семь …» |
| Сообщения | «напиши маме смс, что задерживаюсь», «напиши Ивану в телеграм, что …», «отправь маме в ватсап …» |
| Telegram | «что нового в телеграме», «прочитай сообщения от Маши в телеграм», «напиши маме в телеграм, что …» (после входа, см. docs/TELEGRAM.md) |
| Настройки | «открой настройки», «выключи озвучку», «включи озвучку» |
| Чат | «раздел телефон / заметки / телеграм / система / диалог / все», «покажи все сообщения», «удали последнее сообщение», «очисти чат», «верни сообщение», «верни удалённые», «очисти корзину», «храни историю неделю / всегда», «не храни историю», «смахнутое в корзину», «удалять насовсем» (сообщение можно ещё смахнуть вправо) |
| Картинки | «покажи фото», «выбери картинку», «добавь фото» (открывается системное окно выбора, картинка появляется в чате миниатюрой; нажатие открывает просмотр). Пока просмотр открыт: «дальше», «назад», «закрой». Видео: «покажи видео», «выбери ролик» (миниатюра с кнопкой воспроизведения; нажатие открывает плеер). Пока открыто видео: «пауза», «продолжи», «перемотай на 10 секунд вперёд/назад», «быстрее», «медленнее», «на весь экран», «выйти из полного экрана». Субтитры и качество: следующие этапы (docs/MEDIA.md) |
| Возможности | «что ты умеешь», «чем можешь помочь» - список того, что доступно сейчас, и что нет (причина) |

## Слэш-команды
- `/действия ручной|голос|авто` - как агент делает звонки и SMS: вручную, с подтверждением («да/нет») или сразу.
- `/llm профили`, `/llm проверка`, `/llm телефон [URL|удалить]` - языковые модели.
- `/телеграм` (настроить, войти, код, пароль, чаты, выйти) - вход в Telegram, подробно в docs/TELEGRAM.md.
- `/подключения` - внешние службы и состояние ключей (ключи хранятся зашифрованно, показываются маской).
- `/политика` - режимы действий по возможностям; `/политика call авто`, `/политика message голос`, `/политика call запрет`, `/политика call сброс`. Удаление заметок и задач всегда с подтверждением.
- `/журнал [очистить]` - журнал действий агента (что, когда, получилось ли; без текстов сообщений).
- `/непонятое [очистить]` - журнал фраз, которые не поняли правила.
- `/чат` - состояние чата (хранение, корзина) и список голосовых команд для него.
- `/настройки` - окно настроек.
- `/возможности` - что доступно, что нужно разрешить, что недоступно; `/возможности выключить|включить <название>` - отключить возможность (агент перестанет её выполнять и предлагать моделям).
