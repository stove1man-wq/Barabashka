# Планы и решения

## Принципы продукта
- Ядро - собственный набор команд (правила): быстро, офлайн, предсказуемо. Сетевые и локальные модели необязательны, включаются в настройках и нужны для рассуждений и нестандартных вопросов.
- Любое действие агента проверяемо: нельзя выдавать намерение за успешное выполнение; ошибки сообщаются честно.
- Действия вне приложения подчиняются настройке «Действия агента»; разрешения Android запрашиваются при первом использовании.
- Не обещаем универсальную автоматизацию Android: только публичные API и выданные разрешения.
- Коммерческие уровни и расширения проектируются позже, после проверки реальной пользы (контракт инструмента уже есть).

## Сделано
Голос офлайн, правила, задачи/заметки/напоминания/будильник, погода без VPN, телефонные действия, открытие приложений, звонки и SMS по контактам, чаты в мессенджерах, настройки и режим аватара, журнал непонятого, опциональные модели (Ollama, OpenRouter/Groq, на телефоне).
