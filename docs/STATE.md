# Состояние проекта Barabashka

Короткий файл для начала каждой сессии: что сделано, что решено, что дальше. Обновляется после каждого этапа.

## Сделано (проверено на телефоне)
- Голос (Sherpa-ONNX, GigaAM v2 RU), чат с разделами, команды, маркетплейсы (Ozon/Wildberries по ссылкам).
- Медиа: этап 1 (фото), этап 2 (видео в приложении), этап 3 (полный экран, поворот, Back, голос).
- Меню «＋», правки команд («делить», поиск в интернете, Яндекс Го), точные напоминания включены в настройках Unity (29.10).
- Режим настроек в чате (шестерёнка последней в ряду), страницы настроек через `SettingsRegistry`.
- Основа настроек (без изменений на экране): реестр страниц `SettingsRegistry` и страницы `Core/Settings/`.
- Голосовые команды на страницах настроек: работа с `SettingsVoice.TryHandle`, режим настроек через голос.

## Принятые решения
- Unity (C#) основная платформа; Android Studio только проверка. Блоки (интерфейс, ядро, плагины, сеть) независимы.
- Сеть: ядро работает без внешней сети, зарубежные сервисы только необязательные (риск блокировок VPN). Приоритет LLM: локальная, российские облачные, зарубежные.
- Мессенджеры: MAX вместо Telegram (Telegram приостановлен), путь через уведомления и интенты; бот MAX необязателен; активный провайдер переключается настройкой и командой.
- Видео: источник = плагин (Search, Resolve); три уровня: прямой поток, встраиваемая страница, обычная страница.
- Покупки: человек всегда нажимает «оплатить»; автоматизация через доступность не используется.

## Порядок работ
1. Готово: правила сети, мессенджеров и источников видео (контракты и документы: `docs/ARCHITECTURE.md`, `docs/MESSENGERS.md`, `docs/MEDIA.md`).
2. Этап укрепления (идёт): чистка (старый PowerShell-мост, временные файлы сборки), Edit Mode тесты (`Assets/Tests/EditMode`), слой связи `IConnectivity` с профилями адресов, настройка маркетплейса по умолчанию, сверка документов.
3. Прототип сервера меток окружения и проверка работы на телефоне без ПК (сначала российские облачные модели).
4. Источники видео (direct-link, затем один российский), субтитры, качество; такси (`ITaxiProvider`: оператор по умолчанию или установленный на телефоне, открытие приложения с адресом); документы через «＋».
5. MAX: провайдер `max-notifications` (уведомления и диплинки).
