# Telegram в Barabashka (под личным аккаунтом, через TDLib)

> Статус: приостановлен и необязателен. Основной мессенджер - MAX, см. docs/MESSENGERS.md.

Агент входит в ваш аккаунт Telegram как отдельное устройство (как Telegram Desktop), читает чаты и отправляет сообщения от вашего имени по режиму действий. Используется официальная библиотека Telegram TDLib. Сейчас работает только на Android (arm64).

## Разовая подготовка
1. **Ключи приложения.** На https://my.telegram.org войдите своим номером, откройте «API development tools», создайте приложение (название любое). Запишите `api_id` (число) и `api_hash` (32 символа). Это ваши личные ключи, никому их не передавайте.
2. **Сборка библиотеки.** В репозитории на GitHub: вкладка Actions -> «Build TDLib for Android» -> Run workflow. Через 20-40 минут появится артефакт `libtdjson-arm64-v8a`. Скачайте, распакуйте и положите `libtdjson.so` в `Assets/Plugins/Android/libs/arm64-v8a/`. В Unity выделите файл: платформа Android, CPU ARM64. Если workflow не собрался, пришлите текст ошибки.
3. Соберите приложение под Android.

## Вход (на телефоне, в чате с агентом)
- `/телеграм настроить <api_id> <api_hash>` - сохранить ключи (хранятся зашифрованно).
- `/телеграм войти +79001234567` - запросить код.
- `/телеграм код 12345` - ввести код из Telegram или SMS.
- `/телеграм пароль …` - только если включена двухэтапная защита.
- `/телеграм` - состояние, `/телеграм чаты` - список чатов, `/телеграм выйти`.
Сообщения с ключами, кодом и паролем остаются в истории чата агента: очистите историю после входа.

## Что умеет
- «Что нового в телеграме» - в каких чатах есть непрочитанное.
- «Прочитай сообщения от Маши в телеграм» - последние сообщения чата.
- «Напиши маме в телеграм, что скоро буду» - по режиму действий: вручную - открывается чат Telegram с готовым текстом; с подтверждением - агент спросит «да/нет» и отправит сам; полный цикл - отправит сразу. Результат проверяется: агент ждёт подтверждения доставки от Telegram.
- Если Telegram не подключён к агенту, «напиши в телеграм» работает как раньше: открывается чат с готовым текстом.

## Ограничения
- Только Android arm64 (на ПК библиотеки нет). Telegram-аккаунт один.
- Вход через почту, регистрация нового аккаунта и подтверждение на другом устройстве не поддерживаются.
- Агент читает чаты, только когда вы просите; сообщения не отправляются на серверы Barabashka и не передаются языковым моделям.
- Данные TDLib лежат в папке приложения, ключ базы - в зашифрованном хранилище. «/телеграм выйти» завершает сеанс.
