# Barabashka

Персональный голосовой ИИ-агент на Unity 6 для Android и Windows: 3D-аватар, офлайн-распознавание русской речи (Sherpa-ONNX GigaAM), собственный набор команд («правила») и по желанию языковая модель для сложных вопросов.

## Что умеет
Задачи, заметки, напоминания и таймеры, будильник, калькулятор, даты, погода (без VPN), фонарик, громкость, заряд, поиск, сайты, карты, открытие приложений, звонки и SMS по контактам, чаты в Telegram/WhatsApp с готовым текстом. Полный список фраз: [docs/COMMANDS.md](docs/COMMANDS.md).

## Как устроено
Сначала фразу разбирают правила (быстро, офлайн). Если фраза непонятна и в настройках включена языковая модель (Ollama, OpenRouter/Groq или модель на телефоне), решает она. Подробнее: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Планы: [docs/ROADMAP.md](docs/ROADMAP.md).

## Сборка
1. Unity 6000.6.5f1, платформа Windows или Android.
2. Модели распознавания речи не лежат в Git (большие): положите их в `Assets/StreamingAssets/sherpa-onnx/models/` (см. `docs/ARCHITECTURE.md`, раздел «Модели»).
3. Откройте сцену `Assets/Scenes/SampleScene.unity`, запустите. На первом запуске нажмите «Настрой меня».
